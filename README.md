# Salary_Data_Analysis
Salary Data Analysis using Python, Pandas, NumPy, Matplotlib, and Seaborn. This project performs data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization to uncover salary trends based on age, gender, education level, job title, and years of experience.


**## Overview

This project analyzes a salary dataset to extract meaningful insights using Python data analysis and visualization libraries. The analysis focuses on understanding salary trends based on employee demographics, education level, job roles, and years of experience.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Features

The dataset contains employee information including:

- Age
- Gender
- Education Level
- Job Title
- Years of Experience
- Salary

## Tasks Performed

### 1. Data Loading and Inspection

- Loaded dataset using Pandas.
- Checked dataset dimensions.
- Displayed column information.
- Verified data types.

### 2. Data Cleaning

- Checked for missing values.
- Removed duplicate records.
- Converted columns to appropriate data types.
- Verified data consistency.

### 3. Statistical Analysis

- Calculated average salary.
- Found maximum and minimum salary.
- Calculated average years of experience.
- Analyzed employee age distribution.

### 4. Gender Analysis

- Counted employees by gender.
- Compared average salaries between male and female employees.
- Visualized gender distribution.

### 5. Education Level Analysis

- Counted employees by education level.
- Compared average salaries across education levels.
- Identified education levels associated with higher salaries.

### 6. Job Title Analysis

- Identified the most common job titles.
- Calculated average salary for different job roles.
- Determined the highest-paying job positions.

### 7. Experience Analysis

- Analyzed the relationship between years of experience and salary.
- Compared salary growth across experience levels.
- Identified experience ranges with the highest salaries.

### 8. Correlation Analysis

Analyzed relationships between:

- Age
- Years of Experience
- Salary

Generated a correlation heatmap to understand feature relationships.

### 9. Data Visualization

Created:

- Histogram for Salary Distribution
- Bar Chart for Education Level Counts
- Bar Chart for Gender Distribution
- Pie Chart for Education Level Distribution
- Scatter Plot between Years of Experience and Salary
- Scatter Plot between Age and Salary
- Correlation Heatmap

## Key Insights

- Employees with higher education levels generally earn higher salaries.
- Salary increases with years of experience.
- Senior and managerial roles receive significantly higher salaries.
- Years of experience show a strong positive relationship with salary.
- Education level plays an important role in salary growth.
- The dataset demonstrates clear trends between employee qualifications and earnings.

## Conclusion

This analysis demonstrates how Python can be used for data cleaning, exploratory data analysis, visualization, and extracting valuable insights from employee salary datasets. The project helps understand factors influencing salaries and supports data-driven decision-making in workforce and compensation analysis.
